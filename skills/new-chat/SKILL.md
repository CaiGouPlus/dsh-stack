# 新会话 + 自问自答（new_chat / chat_run）

**一句话**：`chat_presets` 看名册 → `new_chat` 建会话 → `chat_run` 发题并拿回正文 → 判读 → 改预设 → 再 `chat_run`。

插件 `@local/dsh-new-chat` 提供四个工具：

| 工具 | 用途 |
|---|---|
| `chat_presets` | 读预设名册（id/显示名/默认/是否不可用） |
| `new_chat({preset?, cwd?})` | 建会话 + 绑预设 + 补写预设选择标记；**不发消息** |
| `chat_say({sessionId, text})` | 只投递、立刻返回（不等回复） |
| `chat_run({sessionId, text, timeoutMs?})` | **发一条 + 等这一轮跑完 + 回传正文** ← 自问自答靠它 |

没有这些工具 = 插件没装或没激活，如实说，不要假装建好了。

## 三条常用链路

**A. 开一局，第一句留给用户**
`new_chat(preset)` → 回报会话 id → 用户自己在那边说第一句。

**B. 替用户开个头（开完就走）**
`new_chat(preset)` → `chat_say(sessionId, "开始")` → 用户在那边接着玩。

**C. 文风回归 / 自问自答（自动化）**
`new_chat(preset)` → 循环：`chat_run(sessionId, 命题)` → 读正文 →（需要时）改预设 → 下一轮 `chat_run`。
一轮一条、串行；返回值里带状态、耗时、工具调用次数、正文字数。

## 文风测试的设计要点

- **命题要像玩家，不像评测员**。写「请用冷峻克制的笔法写一段」＝把风格要求直接喂进去，测出来是指令跟随，不是预设本身。要写玩家真会说的话：「开始」「我来训练场」「更衣室里什么气氛」。
- **对照组要隔离**：同一会话连发多题 = 上下文累积（连贯但会漂）；每题一个新 `new_chat` = 独立样本（干净）。做**改前/改后 A/B** 时用「同预设 + 同命题 + 各起新会话」。
- **拿回来的只有本轮最终正文**：推理块、工具调用标记都剔除了；预设自己调工具（状态块、判骰）不影响读回，工具次数会单独报。
- **超时**：默认等 3 分钟，长文可传 `timeoutMs`（上限 10 分钟）。超时会返回已产出的部分正文并标「超时」，不会静默丢。
- **判读与改法**：用 `style-distill` 的口径（量化指纹 + 声音层）或增强层的检查项判；改预设走 `tavern_preset_update` / `enhance-layer-edit` 的流程；改完**用同一命题重跑**，别换题。
- **成本**：每轮是一次完整模型调用（含全部注入）。跑 5 轮 ≈ 5 次长调用，批量前先说清要花多少。

## 硬约束

- **不要对当前会话自己调 `chat_run`**（会等一个由自己产生的回合，直接自锁）；工具会拒绝，换个目标会话。
- **一次只发一条**；确要连跑多轮，就在本回合里连续多次 `chat_run`，不要并发刷同一会话。
- **不在已有会话上换预设**：做不到（turnBoundary 闸门）。换预设 = `new_chat` 新会话。
- **不猜预设**：匹配不上/有歧义时工具返回候选列表，照候选再调。
- **别把 `standard` 当默认塞给玩酒馆的用户**：它没有酒馆注入。
- 标了「不可用」的预设不要选；真传了会被拒并给出 broken 诊断。

## 失败时怎么报

| 现象 | 含义 | 怎么说 |
|---|---|---|
| 返回 `预设选择标记：未写入` | 拿不到该会话的 Agent，面板不会注入 | 明说「可能不会注入」，别打包票 |
| `chat_run` 状态「超时」 | 回合没在期限内结束 | 报耗时 + 说正文可能不完整；要更久就调 `timeoutMs` |
| `chat_run` 正文是空占位 | 还在跑工具 / 被中断 / 空回复 | 照实说，别编内容 |
| 返回一串候选 | 预设名没匹配上/有歧义 | 念给用户挑，再调一次 |
| 报「没有 sessionController / agentPresets 服务」 | 部署缺服务 | 如实说装不了 |

## 与酒馆面板的关系（重要）

- 会话头里的 `agentPreset` 只是**出生值**，面板的注入决议**不认出生值**（当年防静默注入的修复）。
  所以 `new_chat` 建完会补写一条 `agent-preset/selected`；**没有这条，新会话在面板眼里等于「没选预设」**，角色卡/世界书不注入 —— 测出来的文风会是「没有设定的空壳」，白白浪费一轮。
- 想确认注入生效：那一轮的系统提示里应出现「【预设来源声明】」「# 角色卡：…」。
- 本 skill 不碰面板数据；改卡/世界书用 `tavern_*` 那套工具。
