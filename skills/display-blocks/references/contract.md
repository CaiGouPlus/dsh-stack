## 一、块级键

| 规范键 | 别名 | 作用 |
|---|---|---|
| `名` | `名称` `title` `name` | 卡片标题（省略则用类型名/标记名） |
| `类型` | `type` `类别` | 决定图标 + 类型徽章 + **默认强调色** |
| `稀有度` | `rarity` `品质` | 查词表上色，并作为强调色第二顺位 |
| `色` | `颜色` `强调色` `accent` `color` | 显式强调色（**压过稀有度**），认 `#hex` / 色码 / 色名 / 稀有度词 |
| `节` | `sections` `分节` `区块` | 分节数组（结构主体） |
| `字段` | `fields` `属性` | 扁平键值表（不分节时的快捷写法） |
| `条目` | `items` `entries` `列表` | 数组；元素可为字符串或 `{名,稀有度,字段,备注,色}` |
| `备注` | `note` `notes` `说明` | 脚注 |

## 二、节级键

| 规范键 | 别名 | 作用 |
|---|---|---|
| `名` | `名称` `name` `title` `标题` | 节标题（省略 = 无题节，只适合整段文本） |
| `值` | `内容` `value` `body` `text` | 节的内容，形状决定版式 |
| `图标` | `icon` | 覆盖该节的默认图标 |
| `布局` | `layout` `样式` | `自动`（默认）/ `文本` / `键值` / `列表` / `标签` |
| `色` | `颜色` `强调色` `accent` `color` | 该节标记线与标题的颜色 |
| `稀有度` | `rarity` `品质` | 该节颜色改从稀有度取 |
| `折叠` | `收起` `fold` `collapsed` | `true`=默认收起 / `false`=默认展开 / 省略=按位置（第一节展开，其余收起） |
| `节` | `sections` `分节` | 嵌套子节（深度上限 4） |

**版式自动判定**：字符串/数字 → `文本`；数组 → `列表`；对象 → `键值`；对象里带 `节` → 继续分节。

**折叠**：具名节都可折叠（**DND 皮肤档案控制台同一套策略**：隐藏控件 + label 头 + `:has` 显隐）。
默认「第一节展开、其余收起」；想让某节始终摊开就写 `"折叠": false`，想强制收起写 `"折叠": true`。
具名节 ≥2 时自动带「展开全部 / 全部收起」。**无标题节永远展开**（没有节头就无处可点）。
**规则与节名无关** —— 自定义标记 / 自定义节名 / 未知版式照样成节、照样可折叠。
`折叠` 是描述字段，不会漏进正文。

## 七、卡侧声明【展示规范】

```
【展示规范】
稀有度: 秘宝=#00e5ff, 凡品=#9aa0a6
颜色: warn=#ff9800, 血红=#8b0000
块: 秘宝=💎|秘宝图鉴|天蓝
节: 外貌=🪞|蓝, 技能=📜|标签|暗金
```

- `词=值` 一行多条，逗号分隔；
- 块的取值 `图标|标题|默认色`（后两段可省）；
- 节的取值 `图标|版式|默认色`；**段位缺失时按「是不是版式名 / 像不像颜色」判定**，不瞎猜；
- 增量覆盖 + **补键不改键**：只写图标不会洗掉默认色；写坏的行整体忽略。

## 九、与 DND 皮肤的分工

`商店` / `升级` / `车卡` / `状态更新` / `状态更正` 这五个标记由 DND 皮肤自己的面板渲染
（`dsh-display-blocks` 默认不接管，透传原文）。写这五个标记请遵守皮肤契约
（`D:\DSH\dnd-plugin\contract\machine-blocks-pack.json`），不要用本契约的通用形状。
