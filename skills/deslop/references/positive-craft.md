# 加法层：小说感与张力

> 配套 `SKILL.md`。前面 12 类病灶治的是**冗余型** AI 味（堆砌、套话、模板）。这一份治**贫瘠型** AI 味（扁平、没张力、没个性）。
> **只做减法不会自动产生好文字。** 删掉废话之后，你得往上加东西。

---

## 0. 两种 AI 味，两种治法

| | 冗余型 | 贫瘠型 |
|---|---|---|
| 表现 | 堆砌、套话、比喻过密、破折号滥用、总分总结构 | 扁平、干、没张力、没个性、读不出情绪 |
| 像什么 | 客服写的年终总结 | 说明书 / 分镜脚本 / 新闻通稿 |
| 治法 | **减法**（删、破对称、限配额） | **加法**（加欲望、加态度、加口语、加挤压） |
| 前 12 类病灶 | ✅ 治这个 | ❌ 治不了 |
| 本文档 | ❌ | ✅ |

**典型误诊**：把贫瘠型当成冗余型治。稿子已经够干净了，还在一味删——越删越薄，最后变成"没有 bug 但也没有人"的文字。

---

## 1. 小说感 vs 散文感

**一句话判据**：散文写「我看到了什么、我想到了什么」；小说写「我**想要**什么、什么**挡着**我、最后**变成**了什么」。

### 五个可操作的转换

| 散文式 | 小说式 |
|---|---|
| 观察环境 | 在环境里**找**某样东西 / **躲**某样东西 |
| 描述感觉 | 感觉**迫使他**做一个动作 |
| 陈述事实 | 事实**改变**了他的计划 |
| 回忆背景 | 背景**被某句话**勾出来 |
| 写出情绪 | 情绪**导致**一个选择或一次失误 |

### 自检：叙述里有没有"想要"

数一下叙述中「想 / 要 / 打算 / 得找 / 不敢 / 忍住 / 试着 / 伸手 / 盯住」这类**意图词**。

- 每 100 字叙述 ≥ 0.8 个 → 叙述是欲望驱动的（有小说感）
- 每 100 字 < 0.4 个 → 叙述是观察驱动的（像散文）

**注意**：这不是"多加几个『他想』"。意图词要落在**动作**上——「我先找出口」「他摸向腰侧」「我盯住那只手」——而不是「他想逃」。

## 2. 张力从哪来

张力 ≠ 形容词，张力 = **读者想知道接下来会怎样**。

### 六个来源

1. **信息差** — 读者知道而人物不知道（或反之）。最强的免费张力。
2. **代价** — 每次选择必须**失去**点什么。没有代价的选择不构成情节。
3. **时限** — 有期限，而且期限要**渗进每一段**，而不是只在开头交代一次。
4. **不可逆** — 打碎的东西修不好、说出口的话收不回。不可逆动作是最好的段落收尾。
5. **未说出口** — 最强的一种：人物想说但没说。让读者去猜那句话是什么。
6. **打断** — 话被打断、动作被打断、刚要说的时候门响了。

### 技法：把「并列」改成「挤压」

这一条是**张力不足最常见的成因**。

数一下句间的因果 / 转折词（于是 / 所以 / 但 / 却 / 结果 / 没想到 / 反倒 / 这才 / 原来）每 100 句的出现次数：

- ≥ 15 个 → 句子在互相挤压
- < 8 个 → 句子在排排坐（`A。B。C。`），读者只是在收信息，不是在等结果

❌ 并列（每句独立，读起来是清单）：

> 我把门板斜靠在门框上。然后开始翻。行囊第一个。两套戏服。一卷铺盖。五支蜡烛。

✅ 挤压（每句都在推下一句）：

> 我把门板斜靠在门框上，挡不住人，但至少走廊看不进来。可我刚蹲下去就停住了——行囊是敞着的。醒来的时候它明明是扣好的。

（后一句的每个分句都被前一个分句逼出来：**但**、**可**、**明明**）

**注意**：不要为了凑连接词而滥用。关键是**事件之间真的有因果关系**，而不是贴一个"于是"上去。中文小说允许省略连接词，靠语序和标点表达因果——所以这条的标准不是数词，是问自己：**这一段里，后一句是被前一句逼出来的，还是自己独立站着的？**

## 3. 留白：不精确的权利

**小说不是逻辑证明。它只需要「说得通」，不需要「严密」。**

把每一处动机、每一句台词的完整含义都交代清楚，是 AI 最容易犯的过度行为——因为它被训练成"完整"。而**明确性是有代价的**：你解释掉的每一处，读者就少参与一次。

### 3.1 留白 vs 漏洞

| | 留白（要的） | 漏洞（不要的） |
|---|---|---|
| 发生在 | **解读层**：为什么、什么意思、后来怎样 | **事实层**：谁、在哪、什么时候、发生没发生 |
| 读者反应 | 自己去想，参与感 | 出戏，觉得作者没想清 |
| 判据 | 读者**能**补出一个自洽解释（可以有好几个） | 读者补不出来，或补出来跟后文撞车 |

**一句话：留白是「读者能填」，漏洞是「读者填不上」或「填了会撞车」。**

### 3.2 可以留白的七处

1. **动机** — 人物做了某事，不说为什么。读者会自己找理由。
2. **意义** — 一个动作可以有多种解读，不点明是哪一种。
3. **后续** — 一件事的结果可以延迟揭示，或只给半句。
4. **指代** — 「那个东西」「他们」「有人说」，不必每次都点名。
5. **对话的前半句** — 双方都懂的事，只说后半句。
6. **问题** — 提出但不解答。
7. **因果** — 两件事并置即可，不必写「因为…所以…」。中文小说尤其允许靠语序暗示因果。

### 3.3 最常被写死的三种留白

**① 动机被解释完**

❌ 木桩没回头。**他大概不觉得一个半身人小孩值一根短棍。**
✅ 木桩没回头。

（删掉后读者自己会想"他为什么不在意"——这个思考本身就是参与。）

**② 台词的言外之意被点破**

❌ 「我可没看见上船的。」他说。**他的意思是那两个人根本没上船。**
✅ 「我可没看见上船的。」他说。塔姆笑起来，缺牙的地方漏风。

**③ 情绪被命名**

❌ **我知道他在试探我。**「三天。」他说。
✅ 「三天。」他说。

### 3.4 边界（这几条不能松）

- **不能矛盾。** 前后不一致是 bug，不是留白——读者会出戏。
- **不能靠模糊逃避该交代的。** 关键转折不能糊过去。留白是选择，不是逃避。
- **人物行为要有「说得通」的动机，但动机不必被说出来。**
- **机器可读的状态栏要准。** 叙述可以留白，状态块（`<status>` 这类）不行——它是要被程序解析的契约，不是文学。

### 3.5 一个反直觉的推论

**「给读者想象空间」不等于「写得模糊」。**

最好的留白是**信息很具体、但意义开放**：

> 她把手机翻过来扣在桌上，屏幕朝下。

信息是精确的（动作、方向），意义是开放的（生气？不想被看到？只是习惯？）。

反过来，「她心情很复杂」这种句子**看着模糊，其实什么都没留**——因为读者没有可以填的东西。

> **所以：留白要在「意义层」留，不要在「信息层」留。**
> 这也是为什么它和「写得具体」不冲突——你前面练的具体化能力，正是留白的前提。

### 3.6 和「加态度」的区别

上一节要求「叙述者要有态度」，这一节要求「叙述者别解释完」。这两条**不矛盾**：

- **态度 = 叙述者在场**（觉得荒唐、不对劲、好笑）→ 加
- **解释 = 叙述者替读者推理**（他大概是…、这说明…、原来是因为…）→ 减

**在场但不抢占。** 一个有态度的叙述者会说「这不对劲」；一个过度解释的叙述者会说「这不对，因为他是想让我先开口，这样他就能…」——后者把读者的活干了。

## 4. 对话：让它像人说话

### 4.1 语气词是最高杠杆的一招

**这是投入产出比最高的一项修改。**

真实中文口语里，语气助词大约每 **15–25 字**出现一次。同 100 字对话应有 **4–7 个**。

如果实测每 100 字对话 < 2 个，说明对话缺"人味"——听起来像字幕，不像人在说话。

可用的语气词：

| 类别 | 词 |
|---|---|
| 陈述 / 确认 | 吧 呢 啊 嘛 呀 哦 噢 嘞 咯 啦 哟 呗 哇 唷 |
| 迟疑 / 停顿 | 嗯 唔 呃 唉 欸 |
| 轻蔑 / 不耐 | 哼 啧 切 嘿 |

**同一个意思，加不加语气词是两个角色：**

| 改前 | 改后 |
|---|---|
| 「我没看见上船的。我看见的是没上去的。」 | 「上船的？我没瞧见。」他笑起来，「我瞧见的是没上去的。」 |
| 「行。巷尾最里头那扇绿门，瘸腿玛拉住那儿。」 | 「行吧。」他把马甲下摆一撩，「巷尾最里头那扇绿门，瘸腿玛拉住那儿。」 |
| 「你别以为白听。你欠我一次，我记账的。」 | 「你别以为白听啊。」他回头，「你欠我一次，我记账的。」 |

**关键约束**：**必须留至少一个不用语气词的角色**。全都加就变成另一种同质；有了对比，语气词才有信息量（谁热络、谁冷淡、谁在装）。

### 4.2 台词要"不完整"

真人说话有省略、重复、说反、自我修正。台词完成度太高就是字幕。

| 技法 | 例子 |
|---|---|
| 省略主语 | 「不认识。」而不是「我不认识那个。」 |
| 重复强调 | 「三天。三天了。」 |
| 自我修正 | 「我昨天——不是，前天晚上。」 |
| 说反再改口 | 「我没想……算了。」 |
| 答非所问 | 问 A 答 B，反而暴露更多 |
| 插入自我评论 | 「——那时候我还以为他死了，蠢吧。」 |

### 4.3 每个角色的口癖表（动笔前先定）

**最常见的失败不是"全员同腔"，而是"全员同一档简洁"。** 所有人都惜字如金，读起来不像一群人，像一个人分身。

写对话前先给主要角色填这张表：

| 维度 | 取值举例 |
|---|---|
| 句长 | 极短（2–6 字）/ 中（10–20）/ 长而绕（25+） |
| 口癖 | 反复出现的词或句式 |
| 语气词倾向 | 无 / 少量 / 大量 |
| 教育程度 | 书面语 / 市井口语 / 粗话 |
| 会不会跑题 | 从不 / 经常 |

**示例（同一场戏里的五种人）**

| 角色 | 句长 | 口癖 | 语气词 |
|---|---|---|---|
| 打手 | 极短 | 只说动词，重复单字 | 几乎没有 |
| 码头小孩 | 快而碎 | 三个词挤一起，插自己评论 | 吧 嘛 呗 欸 |
| 老妇人 | 中长、绕 | 先反问再回答，用「孩子」 | 唉 啊 呢 |
| 老水手 | 中长、跑题 | 一句话里塞三十年经历 | 嘞 咯 啊 |
| 商人 | 中、绕圈 | 先报价再说条件 | 嘛 呀 哦 |

## 5. 情绪要有档位

**持续的紧张等于没有紧张。** 一直维持同一个情绪档位（比如"警觉 + 冷静"），读者会钝化。

具体做法：

- **松一下再紧** — 紧张段落之间插一段松弛：笑一下、饿了、想起一件无关的事。
- **身体先于语言** — 情绪冲上来时先写生理反应，隔一句再写判断。
- **让叙述者有态度** — 叙述者可以对世界有偏见、有洁癖、有怕的东西。数一下叙述中的态度 / 判断词（奇怪 / 荒唐 / 不对劲 / 难怪 / 居然 / 偏偏 / 见鬼），每 100 字叙述 **≥ 1 个**才算"叙述者在场"。

> **一个对什么都不评判、什么都不觉得奇怪的叙述者，读者无法跟他建立感情。** 这是"散文感"和"冷淡感"最常见的来源。

## 6. 修饰词：要精确，不要华丽

前面说"删形容词"，那是针对**无效修饰**。要区分：

| 类型 | 例子 | 处理 |
|---|---|---|
| 空泛评价 | 美丽的、震撼人心的、无比愤怒的 | **删** |
| 精确限定 | 半截的、发潮的、缺了一颗的、大了两号的 | **留，甚至要加** |
| 感官具体 | 泛金的、黏的、凉的、锈的 | **留** |
| 比喻 | 像…… | 限额（≤5‰） |
| 程度副词 | 很、非常、格外 | 少用（靠具体代替程度） |

**判据**：这个修饰词是否**缩小了想象范围**？

- 「一张旧桌子」→ 缩小了 → 有效
- 「一张美丽的桌子」→ 没缩小，只贴了个标签 → 无效

## 7. 实测画像：怎么判断自己落进了贫瘠型

| 指标 | 偏低线 | 含义 |
|---|---|---|
| 对话语气词密度 | < 2 / 100 字对话 | 对话不像人说话 |
| 叙述意图词密度 | < 0.6 / 100 字叙述 | 叙述是观察驱动，不是欲望驱动 |
| 叙述者态度词密度 | < 0.8 / 100 字叙述 | 叙述者不在场，没有态度 |
| 句间因果 / 转折 | < 10 / 100 句 | 句子在排排坐，不在挤压 |

`deslop-lint.mjs` 会把这四项单列成「加法层」输出。**它们报低不是"没删干净"，是"没加东西"——这时候不要继续删稿，要往上加。**

## 8. 改写示范

**原文**（纯观察、并列节奏、无意图、无态度）：

> 我扶着床沿站起来。腿是麻的，脚踝在落地那一刻打了个趔趄，手撑住墙才没跪下去。掌心擦过墙面，蹭下来一层湿冷的灰泥。这具身体不习惯被别人的意志用——但它撑着站住了。
>
> 屋里比我刚睁眼时清楚得多。一张矮床，一套铺盖，倒下的凳子，我自己的行囊还靠墙立着。窗边桌上摆着个空酒瓶和两只没洗的杯子。地板上散着三截断弦。
>
> 墙角立着一个琴盒。
>
> 它不是我的。黑漆木头，铜扣，比我自己的那把琴用的软皮套讲究得多。盒盖半开，内衬是暗红色的天鹅绒，里面凹着一把琴的形状。
>
> 里面没有琴。

**改后**（加意图 + 加态度 + 加推理 + 破并列）：

> 我扶着床沿站起来，腿是麻的，脚踝落地那下打了个趔趄，手撑住墙才没跪下去。掌心蹭下来一层湿冷的灰泥。这具身体不习惯被别人的意志用，但它撑着站住了。**可它站住之后，我发现我不知道该干什么。**
>
> **所以我先找出口。** 门被那人堵着，窗户在右手边，外面是防火梯。**然后我找能拿的东西。**
>
> 屋里比我刚睁眼时清楚得多：一张矮床，一套铺盖，倒下的凳子，窗边桌上一个空酒瓶和两只没洗的杯子。地板上散着三截断弦。**断弦是新的。断口还翘着，没落灰。**
>
> 墙角立着一个琴盒。
>
> 它不是我的。黑漆木头，铜扣，比我那把琴的软皮套讲究得多。盒盖半开，内衬是暗红色天鹅绒，凹着一把琴的形状。
>
> 里面是空的。
>
> **我认得这种东西。** 这种内衬是照着琴身压出来的模具，一个盒子只装一把琴，所以它原来的主人是个**买得起定制盒**的人。**而他现在把琴弄丢了，还把盒子留在这儿。**
>
> 门口那人没说话。他的视线越过我，落在盒子上，停了两秒。

改了什么：

| 改动 | 加的层 |
|---|---|
| 「可它站住之后，我发现我不知道该干什么」 | 叙述者态度（承认茫然） |
| 「所以我先找出口」「然后我找能拿的东西」 | 意图 / 欲望驱动 |
| 「断弦是新的。断口还翘着，没落灰。」 | 具体感官 + 信息差伏笔 |
| 「我认得这种东西……一个盒子只装一把琴」 | 叙述者介入 + 推理（制造"这意味着什么"的张力） |
| 「而他现在把琴弄丢了，还把盒子留在这儿」 | 把静态事实变成**意义**，落到"代价/异常"上 |
| 删掉一处破折号、一处三段式 | 同时修了减法层的问题 |

## 9. 加法和减法一起用

**顺序很重要**：先加，后减。

1. **加**：意图、态度、口语、挤压、张力钩子 → 稿子会变长、变糙、变活。
2. **减**：套话、模板句式、超配的破折号 / 比喻 / 三段式 → 稿子收干净。

反过来做（先减后加）容易把该保留的具体细节一起删掉，然后又得重新想。

`deslop-lint.mjs` 的改稿顺序已经把加法排在第 6 位（减法之后），但**如果你的加法层全面偏低，应该先做加法**——因为加法层报低意味着稿子的骨架问题，不是皮肤问题。
