# 中文小说 AI 味词表与句式清单

> 配套 `scripts/deslop-lint.mjs`（注意：**不是一一对应**——词表约 40 条里只有标注「✅ 机器 · 判据名」的条目在脚本 `BANNED`/`EXT_PATTERNS`/结构判据里有正则，「⛔ 仅人工复查」「⚠️ 仅统计」的条目脚本不查或只出数不判；改机器判据要同步改脚本）。
> **重要**：词表是**线索**，不是违禁词。单独出现一次通常不算问题；只有**反复出现、脱离事实、或让句子空转**时才处理。按词表机械替换是无效功——真正要动的是结构。

## 一、句尾补语（一律可删）

| 形式 | 说明 | lint 判据 |
|---|---|---|
| 他终于（明白 / 懂得 / 意识到 / 看清）了（一切 / 所有 / 真相） | 典型的伪深度收尾 | ✅ 机器 · 句尾补语（终于明白了一切） |
| 这一刻，… | 后面的分句基本都是废话 | ✅ 机器 · 句尾补语（这一刻…） |
| （时间 / 空气 / 世界 / 一切）仿佛（静止 / 凝固 / 停住） | 滥用 | ✅ 机器 · 句尾补语（时间仿佛静止） |
| 一切都已不同 / 一切都变了 | 无信息 | ✅ 机器 · 句尾补语（一切都变了） |
| 而这一切，才刚刚开始 | 模板化悬念 | ✅ 机器 · 模板化悬念（才刚刚开始） |
| 命运的齿轮开始转动 | 宿命腔 | ✅ 机器 · 宿命腔 |
| 冥冥之中 / 早已注定 / 注定的 | 宿命腔 | ✅ 机器 · 宿命腔 |
| 这意味着什么，或许只有他自己知道 | 无信息 + 装深沉 | ✅ 机器 · 句尾补语（这意味着什么…） |

|---|---|---|
| 值得一提的是 / 不可否认 / 毫无疑问 / 众所周知 / 不言而喻 / 毋庸置疑 | 全部可删 | ✅ 机器 · 议论文腔 |

## 四、比喻标记词 ✅ 机器 · 比喻词密度 / 含比喻的段占比

`仿佛` `宛如` `宛若` `犹如` `恍如` `好似` `好比` `恰似` `像是` `就像` `如同` `似的` `像`

**注意 `像` 的假阳性**：词表里的「像」不都是比喻。脚本的 `SIMILE_SRC` 已按**整词**排除——

- **X像 复合词**（`像` 是语素）整词排除：`好像` `图像` `想象/想像` `偶像` `形像` `录像` `摄像` `肖像` `画像` `影像` `声像` `实像` `假像` `相像` `雕像` `蜡像` `神像` `遗像` `群像` `佛像` `圣像` `石像` `铜像` `坐像` `立像` `塑像` `铸像` `造像` `虚像` `成像` `显像` `拟像`
- **后字排除**：`像话` `像样` `像素` `像差` `像元` —— 「他太不像话了」**不计**比喻。
- **`影` 双向处理**：`影像` 排除；但 `身影像雾` / `人影像` / `倒影像…` 里「影」属于前词（身/人/背/树/倒…+影），`像` 是比喻谓词 → **照常计入**。
- **故意不排除**：`人` / `头`（「人像蚂蚁」「头像拨浪鼓」是真比喻，误杀代价高于「人像摄影」漏网）；`镜头` `扮相` `事项` `现象` `对象` `景象` `迹象` `印象` `真相` 里根本没有「像」（是 象/相/项/头），只是人工排查线索，不进正则。

**阈值**：每千字 ≤ 5 个。一段最多 1 个（注：脚本的单段卡规当前是 3 处起报，比这条宽）。

## 五、标点预算

| 标点 | 健康密度 | 说明 | lint 判据 |
|---|---|---|---|
| 破折号 `——` | **≤ 5‰**（按字符计；「按处」计约减半） | 见下方专节 | ✅ 机器 · 破折号密度(按字符/按处)、夹注式破折号、破折号单段超限、破折号功能单一 |
| 省略号 `…` | ≤ 4‰ | 情绪化留白，滥用变廉价 | ✅ 机器 · 省略号密度（另有「按处」口径；`……`/`⋯⋯`/`...` 都计） |
| 感叹号 `！` | 叙事段落里 ≤ 2‰ | 靠标点表达情绪是偷懒 | ⚠️ 仅统计（`bang` 有指标，无阈值判据） |
| 分号 `；` | 不宜密集 | 排比式分句是结构对称的信号 | ⛔ 仅人工复查（结构性排比可由「三段式堆砌」兜一部分） |

**引号**：中文小说用 `「」` 或 `""` 都可以，但**全篇要统一**。混用一眼可见。

### 破折号专节

破折号是中英文差异最大、也最容易被写成 AI 签名的一个标点。**它的主流用法「陈述——补充」是从英文 em dash 直接搬过来的**，中文小说里并不这么用。

**中文的正当用途只有四种**：

| 用途 | 样子 | 保留？ |
|---|---|---|
| 话被截断 | `"我——"` | 保留 |
| 拖音 | `"来——了——"` | 保留 |
| 硬突转 | 语气急转，少量 | 慎用 |
| 关键补充 | 全篇个位数 | 慎用 |

**三条硬规矩**

1. **禁止成对夹注式** `——插入语——`。中文该用逗号、括号，或把插入语提到句首／拆成独立句。
   ❌ `上一秒还有别的东西——很多画面，很多人声，某个麻烦——下一秒就只剩铁锈味`
   ✅ `上一秒还有别的东西，很多画面，很多人声，某个当时我以为天塌下来的麻烦。下一秒就只剩铁锈味`
2. **禁止用破折号做常规补充说明。**
   ❌ `他的手指在口袋里动来动去——他在数什么东西`
   ✅ `他的手指在口袋里动来动去。他在数什么东西。`
3. **同一段内最多 1 处。** 一段里出现两三个破折号，是最典型的 AI 分布（lint 报「破折号单段超限」；`paraDashCluster` 只是统计字段）。

**替换对照**

| 原文结构 | 改法 |
|---|---|
| `A——B`（B 是解释） | `A。B。` 或 `A，B。` |
| `A——B`（B 是纠正） | 删掉 A 的否定部分，直接写 B |
| `——插入语——` | 用括号，或把插入语前置 |
| `"台词——"`（截断） | 保留 |

**破折号常与「不是 X 是 Y」叠用**，删破折号能同时治掉一半二分壳：

| 原文 | 改后 |
|---|---|
| `指甲缝里嵌着干掉的血，暗褐色——不是虎口这道新伤留下的` | `指甲缝里嵌着干掉的血，暗褐色，已经结了很久。虎口这道伤是新的。` |
| `把堵死的门框让出三分之二——不是让路，是给货主留个位置` | `把堵死的门框让出三分之二，给货主留了个位置。` |
| `有那么一条船靠东头空泊位——不是泊，是靠` | `有那么一条船在东头空泊位上停了一下。靠，不是泊。` |

**最有效的自查法**：把全篇破折号替换成句号或逗号，通读。读起来几乎没差别 → 全删；只有几处替换后明显变差 → 那几处才保留。

**lint 对应检查**：`破折号密度`（超 5‰ 警示、超 9‰ 超限）、`夹注式破折号`、`破折号单段超限`（一段 >3 处）、`破折号功能单一`。注意 lint 只做确定性判定，**不会**自动区分"打断"和"补充"——那需要语义理解，误报率高。所以「引号内 N 处」只是位置统计，不代表那 N 处用法合法。

## 六、生成时自查的 12 条硬禁令

（与 `SKILL.md` 一致，供 lint 报告和人工复查对照）

1. 禁止景物 / 天气 / 心理起笔。 —— ✅ 机器 · 疑似景物起笔（心理起笔 ⛔ 仅人工复查）
2. 禁止句尾补语式总结。 —— ✅ 机器 · 句尾补语组 + 疑似章末金句
3. 禁止「不是 X 而是 Y」「不仅 X 更 Y」。 —— ✅ 机器 · 二分壳 / 递进排比
4. 禁止三段式堆砌。 —— ✅ 机器 · 三段式堆砌（连续多段同构排比；句级的「连续三句同长」另有一条）
5. 比喻每千字 ≤ 5，一段 ≤ 1。 —— ✅ 机器 · 比喻词密度 + 含比喻的段占比（「一段 ≤ 1」⛔ 仅人工复查）
6. 禁止「他感到 X」式情绪直给。 —— ✅ 机器 · 情绪直给（他感到无比…）（其余变体 ⛔ 仅人工复查）
7. 禁止连续三句同长；段落长度必须不均。 —— ✅ 机器 · 连续三句同长 + 段长离散度
8. 章末不升华、不总结、不抒情。 —— ✅ 机器 · 疑似章末金句 + 预告式总结收尾 + 章尾状态总结体
9. 每个角色独立口癖与句长，不许全员同腔。 —— ⛔ 仅人工复查（需要按角色分段对比，脚本不做）
10. 不解释已经写出来的比喻。 —— ⛔ 仅人工复查（语义判断；「叙述者替读者解释」查的是推断式插入，不是这条）
11. 禁止「第 X 章」「伏笔」「读者」等元信息进正文。 —— ✅ 机器 · 疑似元信息穿透
12. 写完自查：哪一句像 AI 写的？重写它。 —— ⛔ 仅人工复查

## 七、脚本参考

```bash
# 单文件
node "D:/DSH/skills/deslop/scripts/deslop-lint.mjs" 第三章.md

# 目录（递归收 .md/.txt）
node "D:/DSH/skills/deslop/scripts/deslop-lint.mjs" 正文/

# 严格档 / 宽松档
node ".../deslop-lint.mjs" 正文/ --profile=strict
node ".../deslop-lint.mjs" 正文/ --profile=loose

# 机器可读
node ".../deslop-lint.mjs" 正文/ --json > report.json
```

退出码：`0` 通过，`1` 有 fail 级问题，`2` 参数/输入错误（缺文件、参数非法）。可直接接进构建脚本或 git hook；`--fail-on=all` 时 advisory 级也算 `1`。
