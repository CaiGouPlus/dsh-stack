## 一、方法论：这三条最值钱

### 1. blocking / advisory 分级 + 真人语料校准

来自 oh-story 的 `check-ai-patterns.js`。他们的做法：

- **只有「真人语料命中 ≈0」的判据才配当 blocking**（每 20 章 ≤1 处，且人工确认确属该句式）
- 其余一律 **advisory**——只提示，不影响退出码
- 每条规则的注释里都写清校准数据（命中率、误报率）
- 校准语料量级：七猫长篇 5584 章 + 黑岩短篇整篇 3983 篇

**已吸收**：`--fail-on=blocking|all`、每个判据打 `硬 / 议` 标记、加法层四项因未经语料校准而降为 advisory。

**未吸收**：真人语料校准本身。本项目的阈值多为语言学估计，**这是当前最大的短板**——见第四节。

### 2. 密度 + 次数双门槛

单次命中在中文里是正常表达，必须 **minHits 与 perKilo 同时达标**才报。

例：微动作复读要求 ≥5 次 **且** ≥6 次/千字。
→ 好处是短文本不会误报，长文本里真正成片复现的才被抓出来。

**已吸收**：`patterns-ext.mjs` 每项都带 `minHits` + `perKilo`。

### 3. scope 限定：只看「引号外叙述」

对话里成片短句、结尾的语气词、系统播报的短行——这些是**正常形态**，不该套叙述的判据。

**已吸收**：`splitDialogue()` 按引号样式分离对话/叙述；`patterns-ext` 每项声明 `scope: narration | all | tail`。章尾类判据只扫**文末 600 字窗口**（剥空白后的可见字数）。

## 二、新检测项（已实现）

| id | 名称 | 分级 | 判据要点 |
|---|---|---|---|
| `quote-emphasis` | 引号强调滥用 | 议 | 叙述里给 1–4 字普通名词加引号划重点 |
| `micro-action-tic` | 微动作复读 | **硬** | 「了一下／了下／拍了两下」式尾巴成片复现 = **删过头的电报体指纹** |
| `stutter-period` | 碎句号 | 议 | 连续 ≥6 个 ≤5 字叙述短句，句号密得像提纲 |
| `action-list-tic` | 动作清单腔 | 议 | 同段堆通用动作动词 + 逗号顿号串成步骤表，读感像监控记录 |
| `reasoning-chain-tic` | 解释链密度 | 议 | 知道／意味着／必须／意识到 **多桶**同时聚集 |
| `reverse-not-is` | 反序对比腔 | **硬** | 「是A，不是B」——二分壳的倒装变体 |
| `negation-parade` | 否定排比 | **硬** | 同句连排 ≥2 个「没有X，」 |
| `cross-negation` | 跨段否定铺排 | 议 | 「不是A。」「也不是B。」「只是C。」三段连排 |
| `voice-contrast` | 音量反差腔 | **硬** | 「声音不高，却…」 |
| `not-is-camouflage` | 二分壳伪装变体 | **硬** | 以为体／让转体／抬价体／换字体（见下） |
| `trailer-ending` | 预告式收尾 | **硬** | 文末窗口内的「没人知道」「才刚刚开始」「即将降临」 |
| `trailer-summary` | 章尾状态总结体 | **硬** | 文末窗口内的「这一夜注定」「命运齿轮」「新的篇章」 |

- **`.deslop-ignore` 白名单**——每行一个判据 id，作者有意选择的写法可豁免
- **`--fail-on=blocking|all`**——advisory 默认不影响退出码

- `98dfab2a`（建卡会话）：反序对比腔 3 处、否定排比 2 处——与人工核对一致
- `灰雀`、`4adcb62d`：扩展项 0 命中（说明它们的问题不在这些模式上）

## 三、最有价值的一条：禁的是「修辞动作」，不是「字面」

来自 awesome-novel-agent（GPL，已改写）。**「不是A而是B」有七类外衣**，只抓字面必然漏：

| 外衣 | 例子 |
|---|---|
| 字面翻案 | 不是A而是B。并非A而是B。不在于A而在于B |
| 省字变形 | 不是A，是B。不是A，B才是 |
| 跨句变形 | 不是A。而是B。表面上是A。其实是B |
| 换字变形 | 与其说A，倒不如讲B。与其说A，毋宁说B |
| **以为体** | 你以为A，其实B。我一直以为A，后来才发现B |
| **让转体** | 看似A，实则B。大家都说A，可真相是B |
| **抬价体** | A不重要，重要的是B。真正值钱的从来都与A无关 |

**拆法只有一种**：找到这句话原本想下的判断，从正面说出来。

我们原来的 lint 只抓了前两类字面形式，**漏了后三类（以为体／让转体／抬价体）——它们最隐蔽**。已补进 `not-is-camouflage`。

**推广**：所有句式判据都该问一句「换个字继续做同一个动作，能不能绕过我的正则？」能绕过，就说明正则抓错了层级。

## 四、看过但**暂未吸收**的（留给后续）

### 1. 真人语料校准基线（oh-story，可直接当参考）

**七猫长篇 125 本 × 前 8 章旁白统计：**

| 指标 | 真人语料 |
|---|---|
| 逗号之间平均字数 | **8.8–9.6 字** |
| 整句平均字数 | **22–24 字** |
| 逗号长句占叙述句比例 | **74–80%** |
| ≤5 字短片段占比 | 约两成（多是孤立的时间词、转折、动作重拍） |

**番茄高分样本 305 章窗口：**

| 指标 | 真人语料 |
|---|---|
| 段落中位字数 | 23.5 字 |
| 50–60 字行宽占比 | 仅 5.1% |
| 平均对话占比 | 20.6% |
| 对话占比 ≥50% | 仅 3/305 |
| 开篇即对话 | 59/305 |

**关键反证**：`地/得` 出现于 **305/305** 章、`很` 275/305、`像/好像/仿佛/如同` 267/305、顿号 176/305、省略号 281/305。
→ **这些高频功能词在真人写作里普遍存在，不能做 0 容忍硬禁令，只能按语境复核。**

> **对我们的意义**：本项目的密度阈值（破折号 ≤5‰、比喻 ≤5‰、加法层四项）都是**估计值，没有语料校准**。按他们的方法论，这些本该是 advisory 而非硬线。当前实现把它们算作"硬"（影响退出码），是因为对**个人写作检查**来说，一个会报警的阈值比一个永远沉默的阈值有用。**知道自己要什么，可以用 `--profile=loose` 放宽，或直接在 `.deslop-ignore` 里按 id 关掉。**

### 2. 他们的句长口径（比百分比配额更易执行）

> 叙述（旁白）默认写成**逗号长句**：一句用逗号串起 2–4 个动作或信息，再落句号；**逗号之间 8–12 字，整句 20–30 字**。短句是**偶尔的孤立重拍工具**，不是叙述的默认写法。

这和本项目的「节奏带」是同一个洞察，但他们给了更直接的执行口径。已在 `SKILL.md` 里作为参考并列。

### 3. 「模式 10 二修伪自然」——对我们加法清单的警告

> 一些"反检测提示词"会把文本推向另一种模板：为了提高突发性而乱倒装，为了真人感而机械加口误和脏话，为了手机阅读而强制每句换行，为了对话占比而把心理和叙述硬改成台词。

**这直接指向我们自己的加法清单**：如果模型机械执行「语气词每 100 字 4–7 个」，就会落进这个坑。已把这条写进 `SKILL.md`。

### 4. 「删除优先判断」

> 每条被标记项先判能否删除，再考虑润色——很多 AI 味句是废话（解释、注水、凑数），润色后照样冗余。

顺序：① 删掉会丢伏笔／钩子／角色特征／情节推进吗？不丢 → 直接删；丢 → 保留信息只改"怎么说"。
**已吸收**为三遍法里的判断顺序。

### 5. 重复语义四类 + 名词降级

| 类别 | 错误例 | 修法 |
|---|---|---|
| 形容词重复 | 兴高采烈地笑着跑过来 | 笑着跑过来 |
| 近义词重复 | 非常重要的关键问题 | 关键问题 |
| 含义重复 | 我好饿，肚子咕咕叫 | 我好饿 |
| **上下文重复（名词降级）** | 上文说"把抗抑郁药扔了一地"，下文只写"药片" | 第二次提起用更模糊简洁的说法 |

**「名词降级」是个很实用的技法**：同一个东西第二次出现时用更简的说法，既避免重复又像人说话。已补进 `positive-craft.md`。

### 6. 叠加式描写（同一动作掰开写三遍）

> 一个动作先写发生，再补感知细节，再补身体反应，分三段依次写完。读者看到的是同一个动作被掰开写了三遍。

**正确做法**：发生、感知、反应三个维度揉进**同一段连续正文**。

e.g. ❌「他拿起笔。手在抖。笔尖又停住。」→ ✅「他拿起笔，笔尖刚碰到纸就偏了，手腕压了两次都没压稳。」

**这一条和本项目的「节奏带」是互补的**：合并三段会让句子变长、段落变厚——同时满足节奏配额和这条判据。已补进 `banned-patterns.md`。

### 7. 反投机边界（不许为反检测做机械改写）

> 不要为了反检测强制每句换行、把 `……` 改成 `........`、把 `地/得` 全改成 `的`、禁用所有顿号/"很"/"像"、强行开篇对话或按三番四证重排章节。
> **去 AI 味是润色，不是结构重写**；除非用户明确要求重写，否则不改变章节顺序、伏笔分布、对话占比和人物信息释放节奏。

已写进 `SKILL.md` 的硬边界。

### 8. style-resolution：风格优先于去 AI

> 本文件的句长、视角、标点、修辞与禁用词是**默认写法**，服从逐维裁决。**不因作者有意选择某写法就机械删除**；获准命中按书级 `.deslop-whitelist` 处理。

**已吸收**为 `.deslop-ignore` 机制 + 「保护创作意图与剧情功能 > 去 AI Gate」的优先级声明。
