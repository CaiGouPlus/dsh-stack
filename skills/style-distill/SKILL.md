# 文风蒸馏指南（大部头语料 → 风格锚）

## 〇、开工前必答三问

1. **样本纯度**：语料是纯手写还是 AI 辅助/润色过？混入 AI 段落 = 把机器味蒸回来，必须剔除。作者是用户本人还是他人？**蒸馏卡必须标注风格来源**（署名作者的作品照实标注；公开发布产出物时的模仿边界由用户自己判断）。
2. **锁定哪个时期**：多本/多年跨度的语料风格会漂移。默认「成熟期为主 + 近期校准，早期只对照」；用户指定则从其指定。
3. **产出用在哪**：目标载体（游戏叙事/网文/同人）与语料体裁不同时，在蒸馏卡里写明「风格正选」与载体规则的**冲突裁决**（哪个赢）。

## 一、全量统计（脚本跑，零抽样误差）

**为什么先跑统计**：大部头的价值就是统计置信度——几百上千万字的分布是「指纹」，抽样只是「印象」。统计是骨架（防跑偏的下限），技法建模才是风格本体，两者缺一不可。

用 `assets/distill_stats.py <语料目录>`（目录下 .txt/.md）。必出指标：

- **句长分布**：≤8 字 / 9-20 / 21-35 / >35 各占比 + p50/p90——**双峰分布比均值重要**（两头重、中等句凹陷 = 真人节奏；均匀中庸 = AI 指纹）
- **单句段占比**、段均句数（段落习惯是强指纹）
- **标点性格**：感叹号/破折号/省略号/问号每万字密度、「了」每段密度
- **对白字数占比**
- **比喻标记词频**（像/仿佛/犹如/宛如…）→ 直接得**负词表**（近零的词出现即穿帮）
- **n-gram 词频**（2-4 字）与**句首/章首习惯**：「的时候」式招牌语法、「愣了一下」式签名词、「XX说道」式标签
- **章尾类型分布**（问句/感叹/对白/陈述收尾）——章尾是结构指纹最重的地方

**注意**：这是「骨架」，别停在这——用户如果说「只有长短句没效果」，是对的，立刻进第二、三阶段。

## 二、分层抽样（切片给精读用）

用 `assets/cut_samples.py <语料目录>` 按 1/4、1/2、3/4 处各切一章。手动调整为三层：

| 层 | 抽什么 | 为什么 |
|---|---|---|
| 成熟期 | 公认写得最好的卷/弧，3-4 万字 | 蒸馏固化上限 |
| 近期 | 最新 1-2 万字 | 锚定「现在的作者」 |
| 早期 | 1 万字 | 只对照，识别旧习 |

每层覆盖多场景类型（对抗/日常/重对白/情绪戏）；排除番外、实验章节、被编辑改过的章节。

## 三、十维精读建模（每本书一个子代理并行）

把切片路径给子代理，按**十维问卷**产出「他写 X 时总是 Y」式可执行规则（每条附 ≤20 字原文佐证）。问卷（可直接转发）：

> ① 取景与信息释放（注意到什么/在哪停/信息时序：先因后果还是果后补因）② 叙事声口（叙述者温度/距离/评论/幽默/反讽/自由间接引语）③ 句式签名（连动/倒装/插入/省略主语/动词偏好/虚词习惯）④ 词汇指纹（高频特色词/口头禅/骂法/明显不用的词）⑤ 比喻系统（喻体来源域/明暗喻/频率）⑥ 对白（标签习惯/台词长度/潜台词/打断）⑦ **情绪表达通道**（愤怒/紧张/疲惫/开心/心动各走什么通道——反应像不像的关键）⑧ 节奏结构（章首切入/章尾收束/场景概述交替/闲笔）⑨ 描写配方（感官优先级/写人先写什么/细节密度）⑩ 人物声口分法（怎么分人/刺激→反应链/配角怎么偷戏）。最后给【招牌三例】（50-100 字原文+一行好在哪）。另请标注**早期特征**（成熟期会收敛掉的写法）。

## 四、合成蒸馏卡

```
# 蒸馏卡 · 文风（来源：<作者/作品> · <N>万字全量 + 分层精读）
## 一、量化维（全量统计：句法节奏/标点性格/对白/比喻矿脉/词汇签名/结构）
## 二、声音层（十维规则，三书以上交叉合成：共性=核心，单书标〔书名〕，旧习标〔排除〕）
## 三、演化裁决（各时期取值对比表 + 明确排除的旧习）
## 四、与目标载体的冲突裁决（风格正选 vs 现有规则，谁赢）
## 五、风格参考例句（见下文政策）
```

**演化裁决示例结论**：破折号从早期 64/万清零 → 写「禁用」；感叹号收敛一半 → 写「少用」；对白率走高 → 取 25-35%。

## 五、装配（风格锚模块）

产出「✨增强丨文风·个人风格锚」（≤3000 字），装进目标预设增强层——**编辑操作走 enhance-layer-edit skill**（格式铁律、备份、逐字节校验在那里）。模块结构：定位/句法与段落/声口/信息与取景/情绪通道/比喻/结构/负词表/风格参考例句/冲突裁决。

**例句政策（本次实战最重要的教训）**：
1. **改写脱敏例句无效**——改写者带的是自己的分布，反而稀释风格。真正拉动分布的是**原文例句**（上下文里几百字原文 > 一百条规则）。
2. **但例句会泄漏**——带人名/细节/比喻的例句会被模型**当素材抄进正文**（实测：例句的护腕/小臂/蜜色被整段复用）。解法：例句配「**示例禁抄**」条款（人名、细节、比喻、句式禁入正文，发现照搬整段换写），且标注「只学节奏与取景」。
3. 用户自己的作品→原句进例句即可；他人作品→短引文+改写混排，公开发布自担模仿边界。

**白名单政策**：把签名表达（如「愣了一下/V 了V」家族）设为白名单时，必须带用量约束（同一轮 ≤1 处）并写「白名单不是模板」——否则会被滥用成新模板（实测「按了按」×3）。

**区间政策**：所有量化值写区间+情绪派生+让步位，禁「不低于/最多 N 次」全局死数——硬配额制造可测的新均匀。

## 六、验证与闭环

1. **体检脚本** `assets/style_check.py <txt>`：任何产出对照指纹打分（分布/T1/负词/签名词），把「感觉还是 AI 味」变成可修数据。
2. **阈值校准**：先拿语料里的**真人章节**跑一遍体检——真人自己也不是满分（实测一处 T1、碎句超标都有）。目标是「与人同侧分布」，不是零命中；追 0 会把文风搞坏（业界共识门禁 <4% 即过）。
3. **盲测**：留一段没参与蒸馏的章节，同场景生成对照，标准是「像他写的但不是抄他」。
4. **回炉**：跑一段时间后做「口头禅镜像」——统计 AI 产出的高频项 vs 指纹，偏离就补条目；风格锚每 1-2 个月复校一次。

## 七、坑清单（实证）

| 坑 | 后果 | 解法 |
|---|---|---|
| 语料混入 AI 段落 | 蒸出机器味 | 开工前问纯度，剔除 |
| 只做统计不做技法 | 「只有长短句，没效果」 | 十维精读必做 |
| few-shot 用改写例句 | 稀释风格 | 原文例句+示例禁抄 |
| 例句带细节 | 被抄进正文 | 示例禁抄条款 |
| 硬配额 | 新均匀体 | 区间+情绪派生+让步位 |
| 白名单无用量 | 被滥用成模板 | ≤1/轮+「不是模板」 |
| 追零命中 | 文风僵坏 | 同侧分布即达标 |
| 早期旧习混入 | 倒退写法 | 演化裁决表明确排除 |
| 不标注风格来源 | 归属混乱 | 蒸馏卡头部注明 |
