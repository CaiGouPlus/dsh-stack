# 拆文复盘（novel-teardown）

把「写完之后凭感觉检讨」换成「按表拆、按分数改」。这不是重写工具，**只出报告**。

## 一、什么时候跑

- 每 3~5 轮一次，或一个卷/一个赛程段落收尾时。
- 明确感觉「这轮不对但说不清哪不对」时。
- 改过增强层之后做 A/B 时（同一题、同预设、各起新会话）。
- **不要每轮跑**：每轮跑等于把自省成本翻倍，且会诱导模型为分数写作。

## 二、输入

最近 1~3 章的**正文**，去掉机器块（`[[…]]{…}`）与自检行。字数不足 800 的先补写再拆。

## 三、第一步：量化（先数，再判断）

把正文落盘，用脚本数这七项，不要凭印象：

| 指标 | 怎么数 | 参考 |
|---|---|---|
| 正文字数 | 去块后字符数 | 与契约核对 |
| 段数 | 非空行 | — |
| 非对白单句段 | 不含引号、且只有一句的段 | ≤2~4 处 |
| 长句数 | ≥40 字的句子 | 1~3 处拖曳句是正选 |
| 对话标签 | 「说／说道／问」计数 | 单一化＝0 分项 |
| 独立镜头人数 | 有专属动作或台词的出场者 | ≤2 |
| 重复动作 | 同一动词/动作出现次数 | ≤3 次 |

脚本骨架（Python，直接改文字即可）：

```python
import re
body = open('ch.txt', encoding='utf-8').read()
paras = [p.strip() for p in body.split('\n') if p.strip()]
nsent = lambda p: len([x for x in re.split(r'[。？！…]+', p) if x.strip()])
single = [p for p in paras if nsent(p) == 1 and '“' not in p]
print(len(body), len(paras), len(single),
      len([s for s in re.split(r'[。？！]', body) if len(s) >= 40]),
      body.count('说道'))
```

## 四、第二步：结构（六项打分，每项 0~2）

直接套增强层的「交稿评分卡」，不另立标准：

1. 镜头 ≤2 人？有没有一人一句台词（台词也算巡礼）
2. 玩家有没有一件当下要办的事？有没有替玩家决策
3. 能不能说出本场价值 X→Y，且两端不同
4. 非对白单句段 ≤2 处
5. 闲笔 ≤1 处，且过「绕路」检验
6. 日期与前文/机器块一致

**9/12 及格，任何 0 分项必须改。** 6 分以下不要改字，先改场景卡重写这一场。

## 五、第三步：症状映射（不要自己发明解释）

分数低的那一项，先去增强层的「症状索引」查对应的模块，照那个模块的动作改。常见对应：

- 镜头 0 分 → 场景·对抗轴（不是删人，是让其余人只被碰到）
- 玩家 0 分 → 场景·玩家戏份（给动作，不给决策）
- 价值 0 分 → 场景·价值翻转（说不出 X→Y 就并场）
- 织体 0 分 → 反八股·节奏锚（并段，不是加长句）
- 闲笔 0 分 → 松弛模块（删掉，不许补新的）

## 六、输出格式（固定三段，不写第四段）

```
【分数】1镜头2｜2玩家1｜3价值2｜4织体0｜5闲笔2｜6日期2 ＝ 9/12
【症状】织体 0：25 段里 12 段单句（48%），对白段与叙述碎段混算
【改法】① 把「声音不大，够这五个人听见」并进上一段
        ② 三处纯氛围单句段合并成一段
        ③ 下一场开头换长句起，破掉一段一句的惯性
```

改法**只给动作，不重写正文**。要重写由作者或主会话决定。

## 七、反模式

- 不要把评分当配额：为拿 2 分去加闲笔、加长句、加镜头，等于换一种均匀。
- 不要用「感觉不错」代替计数：先出数字，再谈判断。
- 不要每轮跑；不要在一次复盘里同时改预设和改稿，两件事分开做。
- 不要把报告写进正文或机器块。
