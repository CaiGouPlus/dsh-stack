# Changelog

版本号跟 `package.json`。本插件不发布到 npm，版本号只用于标记本地迭代节点。

## [0.6.1] — 2026-10-03

### 修复 · **皮肤在场时插件完全不碰 DOM**（关键）

0.6.0 的"让位"不彻底：即使在 `passAll` 模式下，插件仍会把机器块原文**复制进 `dsp-pass` 的 holder 再替换原文本节点**。
而皮肤 `enhanceTextNode` 用 `seenText = new WeakMap()` **按文本节点身份**判定"内容已稳定"
（连续两次相同 **且 ≥900ms**）才允许 `replaceChild` —— 那是它防"流式冻结"（WB-080）的机制。

⇒ 插件换个节点身份，皮肤的 WeakMap 就**永远没见过**这个新节点 → **永远不 settled → 永远不包装机器块**
→ 真机表现为：`.dnd-machine` 恒为 0、正文里裸着 JSON、展示块页签不出现。

诊断过程（皮肤徽章计数）：`enh c42/np0/dnd12/m0/u16/w2` —— `u16`（16 次卡在未稳定）+ `machines=0`
把范围锁到"节点身份一直在变"，而唯一在换它的是插件自己。

**修法**：`run()` 里皮肤在场就 `publishApi(); return` —— 机器块与行内装饰**全部归皮肤**，
插件只留 API 与设置面板，一根手指都不碰 DOM。（皮肤不在场时行为不变：内联卡片照旧。）

## [0.6.0] — 2026-10-03

### 新增 · 统一渲染出口（与 DND 皮肤控制台合一）

以前是**两块内容、两套样式、两条代码路径**：皮肤在消息底部画档案控制台，插件在正文里再插卡片。
现在皮肤的控制台是**唯一的渲染出口**：

- **插件暴露渲染 API** `window.__DSP__`：`card(marker, json) → DOM 节点`、`iconFor(marker)`、
  `parse(text)`、`spec()`。皮肤只给骨架（tab/面板/累积/默认选中），**机器块长什么样由这里决定**
  —— 渲染只有一份实现，不会再"皮肤画一套、插件画一套"。
- **`passAll` 设置（三态）**：`自动`（默认，DND 皮肤在场就交给它的控制台）/ `总是交给皮肤` /
  `总是本插件内联渲染`。自动判据是 `<html data-dsh-skin="dnd-tavern">`
  —— 换皮肤或没皮肤时自动退回内联卡片，功能不丢。
- `passAll` 时机器块全部**透传原文**（`:class=dsp-pass`），由皮肤的控制台接管；
  行内标注（稀有度/颜色/骰值）照旧由本插件处理。
- 面板里新增「机器块在哪里渲染（统一出口）」下拉，可随时切回内联卡片排查。

### 新增 · 开合状态记忆（补 0.5.1）

用户点过的开合按 `卡片|节名` 记住（`data-dsp-card` 提供卡片身份），上限 500 条；
宿主/皮肤重渲染把卡片换掉后，下次渲染**还原用户的选择**，而不是回到默认态。

### 夹具

- +2 条：`passAll 时机器块全部透传（正文不动）、行内标注照旧`；
  `passAll 与 ownMarkers 同时给时 passAll 优先`。合计 **52 项全过**。

## [0.5.1] — 2026-10-03

### 修复

- **折叠点不开**（0.5.0 用原生 `<details>` 的翻车）：原生开合靠**浏览器默认动作**，页面上游
  （宿主/皮肤）一拦就失效；而 JS 再 toggle `open` 又会与原生行为**互相抵消**。
  改用 **DND 皮肤档案控制台那一套**：视觉隐藏 `<input type=checkbox>` 嵌在 `<label class="dsp-sec-head">` 里，
  显示由 `:has(> .dsp-sec-head > .dsp-ctl:checked)` 驱动；**点击在 capture 阶段由 JS 接管**
  （`preventDefault()` 掉 label 默认激活 + 幂等 `checked = !checked`）——怎么拦都只有一次、方向正确。
  键盘路径不经过 click（空格切 checkbox 是原生行为），保持可用。

### 新增

- **「展开全部 / 全部收起」**：具名节 ≥2 时才给（一个节没什么可批量的）。
- **开合状态记忆**：键是 `卡片|节名`（卡片身份写在 `data-dsp-card` 上）。
  宿主/皮肤重渲染会把卡片整块换掉 —— 不记住用户的开合，就等于「点了没反应」。
  上限 500 条（长会话清空重来）。
- **可扩展度被夹具锁住**：CSS 规则只看 `:checked` 与类名、**不看节名** —— 词表外的自定义标记、
  自定义节名、未知版式，一样成节、一样可折叠、一样不吞内容。
- 键盘可达：控件视觉隐藏但可聚焦，焦点环画在节头上（`:has(> .dsp-ctl:focus-visible)`）。

### 变更（视觉向 DND 皮肤靠拢）

- 卡片：**顶部 2px 金线**（对齐皮肤状态卡/档案控制台的 2px 金顶栏）、圆角 10→12、
  配色改走 `var(--dnd-*, 兜底)` —— **皮肤激活时自动与皮肤同色，没有皮肤时仍用自带兜底**。
- 节头做成皮肤 tab 的三段式：**序号（mono 9.5px）+ 图标 + 标题**，hover 金底、展开态金底 + 标题提亮。
- 类型徽章改成皮肤的「眉标」形：等宽小号 + `letter-spacing` + 金色描边。
- 无标题节**永远展开**（没有节头就无处可点，藏起来就出不去）。

## [0.5.0] — 2026-10-01

### 新增

- **节默认可折叠（原生 `<details>`，零 JS）** —— 具名节的节头就是 `<summary>`，点一下收起/展开；
  默认「**第一节展开、其余收起**」，对齐酒馆档案面板「常驻最重要的 + 折叠其余」的做法。
  节上可用 `"折叠": true|false` 显式覆盖（描述字段，不会漏进正文）。
  - **无名节不折叠**：没有 `<summary>` 的 `<details>` 会把内容整个吞掉，所以无名节保持普通 div。
  - 嵌套节各自独立折叠；折叠箭头（`.dsp-sec-caret`）收起时旋转 -90°。
  - 夹具 +5 条（共 47）：details/summary 结构、summary 必须是第一个子节点、
    显式覆盖、无名节不被吞、嵌套折叠。

### 变更

- 客户端 CSS 增加 `summary.dsp-sec-head` 的 `list-style:none` / `::-webkit-details-marker{display:none}`
  / `::marker{content:''}`，隐藏浏览器自带的三角标，改用自带 caret。

## [0.4.0] — 2026-09-30

### 新增

- **颜色可声明（四级回落）** —— 颜色不再只有「稀有度」一个来源，卡片 / 节 / 条目都能各带各的颜色，
  且统一走一个入口 `resolveColor()`（认 `#hex` / 色码 / 色名 / 稀有度词）：
  - 卡片强调色：显式 `色` → `稀有度` → 该类型的词表默认色 → 兜底褐。
  - 节强调色：显式 `色` → 本节 `稀有度` → 该节的词表默认色 → 继承卡片。
  - 条目名：条目里加 `色` 直接染色。
  - 认不出来的色值**只跳过这一级**，继续回落，不吞内容。
- **色名表**：内置 30+ 中文/英文色名（`红` `天蓝` `暗金` `玫瑰` `gold` `crimson` …），
  声明位与行内都能用；卡可用 `颜色: 血红=#8b0000` 继续扩充。
- **行内颜色标签开放到中文色名**：`[血红]警示[/血红]` 与 `[g]…[/g]`、`[#00e5ff]…[/#00e5ff]` 等价。
  判据仍是「命中词表 **且** 有闭合标签」——`[传说]` 与 Markdown 链接 `[文字](url)` 不受影响（有专门断言）。
- **词表行支持第三段颜色**：`块: 势力=🏰|势力图鉴|天蓝`、`节: 外貌=👁|蓝|文本`；段位缺失时
  按「是不是版式名 / 像不像颜色」判定，不瞎猜。
- 默认块类型与默认节名各配了默认色（共 9 + 12 条），所以**不写任何颜色也不会一片灰褐**。
- 夹具 34 → **42 项**（新增 8 项颜色用例：resolveColor、卡片回落链、节回落链、词表第三段、
  补键不改键、条目色、两段歧义判定、行内色名与误伤防护）。
- Demo：新增「＋ 带色的块」模板；生效词表面板的块/节 chip 带色点；示例里演示了
  「卡片显式色」与「节显式色」。

### 变更

- `lib/spec.js`：`DEFAULT_COLORS` 扩充色名；`DEFAULT_BLOCKS` / `DEFAULT_SECTIONS` 增加 `color`；
  新增 `resolveColor()`；`blockStyle()` / `sectionStyle()` 返回 `color`；
  `mergeSpec` 改为**补键不改键**（只写图标不再洗掉默认色）。
- `lib/render.js`：强调色四级回落；节把颜色写进 `--dsp-sec-accent` + `data-dsp-color`；
  条目名支持 `色`；**稀有度胶囊与强调色解耦**（改强调色不再染错稀有度标签）。
- `lib/client.js`：节的左侧标记线与标题按 `--dsp-sec-accent` 上色。
- `package.json`：0.3.0 → 0.4.0；bundle 51.3 KB → 57.9 KB。

### 兼容

- 既有写法全部不受影响；唯一的契约变更：解析出的块声明对象多了 `color` 字段（夹具已同步）。
- 视觉上一处有意的变化：默认块类型 / 默认节名现在带默认色（此前一律兜底褐）。

## [0.3.0] — 2026-09-30

### 新增

- **通用「节」结构** —— 机器块不再只认 `字段 / 条目 / 备注` 三个固定槽位：
  块里想开几节、节叫什么、每节放什么形状的内容，**全由 JSON 自己声明**。
  人物的年龄 / 外貌 / 心理 / 状态 / 服装 / 身材 / 技能，想开几个开几个。
  - 四种写法都认：描述对象数组 `[{名,值,图标,布局}]` ／ 映射 `{节名: 值}` ／
    单键对象 `[{外貌: "…"}]` ／ 描述字段之外的键自动成为该节内容。
  - **版式自适应**：字符串 → 文本、数组 → 列表、对象 → 键值；
    `布局` 可强制 `文本 / 键值 / 列表 / 标签`；`图标` 可单节覆盖。
  - **可嵌套**（值里再写 `节`，上限 4 层）；**空节不画**。
  - 词表新增 `节: 外貌=🪞|文本` 语法（只写一段时先认版式名）；
    默认内置 12 个常见节名的图标（年龄 / 外貌 / 身材 / 心理 / 性格 / 状态 / 服装 / 装备 / 技能 / 背景 / 关系 / 目标）。
  - **节名不在词表里照样渲染**，只是没有默认图标。
- 夹具 24 → **34 项**（新增 10 项分节用例：四种写法、自动版式、布局覆盖、词表覆盖、嵌套、空节、次序、安全）。
- Demo：示例人物卡改成分节写法；新增「＋ 分节的块」模板；生效词表面板增加「节的图标 / 版式」一组；
  统计行增加分节数。
- `docs/sections-dark.png`、`docs/sections-light.png`。

### 变更

- `lib/spec.js`：新增 `LAYOUTS` / `DEFAULT_SECTIONS` / `FALLBACK_SECTION` / `sectionStyle()`；
  `【展示规范】` 支持 `节:` 行。
- `lib/render.js`：新增分节机制（`SECTION_KEYS` / `normalizeSections` / `renderSections` /
  `renderSectionNode` / `renderValueNodes`）；字段表与条目列表抽成 `fieldsNode` / `itemsNode`，
  供块顶层与分节内部复用。
- `lib/client.js`：新增 `.dsp-secs / .dsp-sec / .dsp-sec-head / .dsp-chips / .dsp-chip` 样式。
- `package.json`：0.2.0 → 0.3.0；客户端 bundle 39.4 KB → 51.3 KB。

### 兼容

- 既有 `字段 / 条目 / 备注` 写法**完全不受影响**（老用例全绿）；节排在扁平字段表之前渲染。
- 修掉实现期的一个 bug：值里写 `{节: {…}}` 时未拆包，会被当成一个名叫「节」的节
  —— 由新增的嵌套夹具当场抓出。

  - 示例内容覆盖 4 个机器块 + 行内标注 + 皮肤标记透传；一键插入模板（组织 / 人物 / 任务 / 物品 / 自创类型 / 行内标注）。

- `LICENSE`（PolyForm-Noncommercial-1.0.0 官方全文）、本 `CHANGELOG.md`。

### 变更

- **卡片视觉升级为「块状工整」形态** —— `lib/client.js` 的 CSS 整段重写：
  - 卡片：圆角面板 + 左侧渐变强调条（颜色跟稀有度）+ 斜向渐变底 + 悬停辉光。
  - 卡片头：图标色块、加粗标题、类型胶囊徽章、稀有度徽章自动右对齐，底部细分隔线。
  - 徽章底色用 `color-mix(in srgb, currentColor N%, transparent)` 从**元素自身颜色**派生 —— 渲染树无需任何新增字段。
  - 字段表：`dt` 变浅底小标签，两列网格对齐；条目变行式小卡（accent 圆点 + 淡底）。
  - 脚注：虚线分隔 + 次级色；行内 `（传说）` 等稀有度词也升级为同色系胶囊。
  - **主题自适应**：所有灰阶由 `currentColor` / `transparent` 混合派生，不预设宿主是亮是暗。
  - `prefers-reduced-motion` 下关闭过渡动画。
- `package.json`：版本 `0.1.0` → `0.2.0`；`files` 加入 `demo`；新增脚本 `npm run demo`。

### 说明

- 渲染树结构、解析规则、词表语义**均未改动** —— 24 项夹具在升级前后同样通过。
- `color-mix` 需要 Chromium 111+（DSH 桌面端 / 现代 Chromium 均满足）；不支持时徽章只失去底色，文字颜色不受影响。

## [0.1.0] — 2026-09-30

### 新增

- 初始版本：通用机器块 `[[任意标记]]{json}` + 行内标注（稀有度配色 / 颜色标签）。
- 词表驱动：卡侧 `【展示规范】` 声明，增量覆盖默认词表（写坏的行整体忽略）。
- 分层：`lib/spec.js`（词表）/ `lib/parse.js`（机器块 + 行内）/ `lib/render.js`（抽象渲染树）/ `lib/client.js`（薄 DOM 壳）。
- 抽象渲染树使全部渲染规则可在 Node 内验证：24 项核心夹具 + 客户端入口契约自检。
- 构建链：`tools/build-client.mjs` 生成自注册单文件入口 `lib/client.bundle.js`。
- 安全纪律：渲染树只带 `text`，落 DOM 一律 `createTextNode`，绝不拼 `innerHTML`；客户端每处接触单独 `try/catch`。
- 与 DND 皮肤分工：默认跳过 `商店 / 升级 / 车卡 / 状态更新 / 状态更正` 五个标记。
